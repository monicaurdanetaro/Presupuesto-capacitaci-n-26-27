Cargando presupuesto…
Falta un paso para que los datos se guarden y se compartan: conecta esta página a una base de datos gratuita de Firebase.
  1. Ve a console.firebase.google.com y crea un proyecto gratis (sin tarjeta).
  2. En el menú "Compilación", entra a Realtime Database → Crear base de datos → modo de prueba.
  3. En Configuración del proyecto → General → "Tus apps" → agrega una app Web (ícono </>) y copia el objeto firebaseConfig.
  4. Pega esos valores en el archivo index.html, al inicio del <script>, donde dice var firebaseConfig = {...}, y vuelve a subirlo a GitHub.
Mientras tanto, la app funciona en este navegador pero no se guarda ni se comparte con el equipo.
